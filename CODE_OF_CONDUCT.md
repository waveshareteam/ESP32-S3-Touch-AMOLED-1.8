# Code of Conduct

简体中文请参见 [CODE_OF_CONDUCT_ZH.md](CODE_OF_CONDUCT_ZH.md)。

This project is intended to be a welcoming, practical space for Waveshare board users, customers, contributors, and maintainers.

## Expected Behavior

- Be respectful and constructive.
- Keep issue and pull request discussions focused on reproducible facts, hardware setup, logs, and proposed fixes.
- Assume contributors are working with different board revisions, host systems, toolchain versions, and experience levels.
- Protect private information such as Wi-Fi credentials, keys, customer data, and unpublished hardware details.

## Unacceptable Behavior

- Harassment, insults, discrimination, or personal attacks.
- Publishing private contact information, credentials, customer data, or security-sensitive details.
- Repeated off-topic comments that make an issue or pull request hard to use.
- Public disclosure of suspected security vulnerabilities before maintainers have had a reasonable chance to respond.

## Reporting

For ordinary project issues, use the repository issue tracker and include the information requested by [SUPPORT.md](SUPPORT.md).

For suspected security vulnerabilities, do not open a public issue. Follow [SECURITY.md](SECURITY.md).

Maintainers may edit, hide, or remove comments and may restrict participation when needed to keep the project useful and safe for customers and contributors.
