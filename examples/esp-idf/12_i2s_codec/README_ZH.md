# 12_i2s_codec

[English](README.md)

面向此 ESP32-S3 开发板、改编自 ESP32-P4 平台示例的 ES8311 音频示例。

此版本使用 BSP 开发板定义，通过 ES8311 扬声器输出播放正弦波。由于本开发板使用单一 ES8311 编解码器路径，它刻意避免麦克风回声模式。

该示例遵循 ESP32-P4 I2S 编解码器示例的结构：先配置 I2S，再初始化编解码器控制路径，最后开始播放。ES8311 设置保留在示例中，因此初始化失败会报告为错误，而不会触发 BSP 辅助函数断言。

## 硬件

- ESP32-S3-Touch-AMOLED-1.8 开发板
- USB 数据线
- 连接到开发板音频输出的扬声器或耳机

## 配置

`idf.py menuconfig` 可调整：

- 采样率
- 原始硬件扬声器音量（默认值 70）
- V2 扬声器音量（检测到 CST816 后默认值 90）
- 测试音频频率

默认值补偿了 V2 硬件上观察到的较低音量。使用敏感耳机或不同扬声器测试前，请降低这两个设置。

## 构建和烧录

```bash
idf.py set-target esp32s3
idf.py menuconfig
idf.py build
idf.py -p PORT flash monitor
```

将 `PORT` 替换为开发板的串口。

## 预期结果

串口监视器会报告检测到的硬件代次、选定音量和 ES8311 初始化状态，同时输出正弦波。

## 故障排除

- 如果编解码器初始化失败，示例会记录错误并保持空闲，而不是中止并进入重启循环。
- `bsp_audio_codec_speaker_init` 中出现带有 `i2c_ctrl_if` 的启动循环，表示旧构建仍在使用 BSP 扬声器辅助函数。请重新构建并烧录当前示例。
- 如果未检测到编解码器控制接口，请使用 `08_i2c_tools`。
- 在判定 I2S 故障前，确认连接的输出设备和音量。
- CI 会验证两种 IDF 配置能够编译，但无法验证主观响度；更改编解码器增益或默认音量后，请在硬件上比较 V1 和 V2。
