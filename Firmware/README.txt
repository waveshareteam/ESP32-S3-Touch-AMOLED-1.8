出厂/恢复固件

本目录包含用于设备恢复或恢复出厂状态的预编译固件。
本仓库目前尚未包含这些固件对应的源码和构建说明；后续更新可能补充。
这些二进制文件不参与 GitHub Actions 源码构建，也不会重新打包为 CI 产物。

Factory / recovery firmware

This directory contains prebuilt images for device recovery or factory restoration.
The corresponding source and build instructions are not included in this repository yet and may be added in a later update.
These binaries are excluded from GitHub Actions source builds and are not repackaged as CI artifacts.
